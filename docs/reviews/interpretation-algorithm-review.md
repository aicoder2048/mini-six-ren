## 独立参考与方法

参考[《白虎通·五行》](https://ctext.org/bai-hu-tong/wu-xing2/zh)的五行相生、相胜循环。该站正文直接打开返回 HTTP 403；本次通过该站搜索索引核验相生内容，并通过[《白虎通·卷三》索引](https://ctext.org/bai-hu-tong/juan-san/zhs)核验相胜内容。因此本次没有声称完整通读在线正文或校勘古籍。

相生顺序为木→火→土→金→水→木；相克顺序为木→土→水→火→金→木。“被生、被克”是本项目以左传为主语时的反向命名；同元素记“比和”。这五类穷尽 25 个有序元素对。未将传统概念验证等同于现实预测效力证明。

Reviewer 独立编写[审计脚本](../../scripts/audit_interpretation_algorithm.py)，手工写出 25 格真值表及九宫固定样例，没有用被测结果生成期望值。比较基线时直接从上述提交加载旧预测器、旧关系函数，而非调用固定为更早基线的 `audit_algorithm_changes.py`。旧预测器复用的输入校验、符号加载、五行数据均另做基线逐字节/字段一致性校验。
