原文核对示例：癸卯说明为“癸卯年值年太岁神煞，象征稳健和耐力，提醒一年中的稳定和持续发展。”；冲解释为“卯（兔）与酉（鸡）相冲，木金相克，通常代表冲突和竞争。”；六合解释为“卯（兔）和戌（狗）相合，木土虽有相克但也有相生之象，可能带来复杂的局面。”。丑巳案例四条关系的解释、组合全部与丑牛文件逐字比较，完整结果存于上述 JSON。

额外在临时 JSON 副本中构造两条不同的同类冲关系，第二条组合为“第二条”、解释为“独立参考第二条原文”，但地支仍为卯酉；实际返回顺序为“卯酉冲、第二条、卯酉破”。验证依据地支而非解析组合，且不按关系类别去重。原始数据未修改。

默认年独立时钟替身将 UTC 瞬间真正转换到调用方传入的时区，同时断言偏移为 +08:00：`2025-12-31T15:59:59+00:00` 得 2025，`2025-12-31T16:00:00+00:00` 得 2026。显式 1900、2099 时禁止访问时钟；非法年份、bool、浮点、字符串、容器及非单支输入拒绝。禁用磁盘读取后连续分析仍成功，修改结果中的嵌套地支列表不污染下一次结果。

`loader.py` 另以临时原数据副本验证缺文件、非法 UTF-8、非法 JSON、顶层类型、重复年份、年份与文件地支不一致、神煞类型、非法地支、缺解释、模拟 PermissionError、重复支文件。均抛出含实际路径的 TaiSuiDataError；包装的读取/结构异常保留原因链。重复支在加载汇总处明确点名副本。原有测试另覆盖全部顶层形状、缺可选类别、非项目目录导入等。未纠正项目资料中的非六十甲子记录。
