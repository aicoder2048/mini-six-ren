# Triage 标签

保留 Matt Pocock 的默认标签词汇；在本地 ticket 的 `Status` 中记录。

| 角色 | 本项目取值 | 含义 |
|---|---|---|
| needs-triage | needs-triage | 尚需评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可由Agent实施 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 本次不处理 |

实施与完成状态见 `issue-tracker.md`；这些状态不改变上述五个triage角色的含义。
