# 领域文档

本仓库采用单上下文布局。

探索代码时，先阅读根目录 `CONTEXT.md`（如果存在）和相关的 `docs/adr/` 决策记录。
这些文件尚不存在时直接继续，不必为初始化技能生成空文档；需要澄清术语或记录架构决策时再创建。

当前背景参考为 `specs/codebase-overview.md`，需区分其中的历史快照与修复后对照。需求和验收以任务链接的权威spec为准；项目规范见 `CLAUDE.md` 和 `AGENTS.md`。

- 保持领域术语一致：三传、九宫、五行关系、八字四柱、农历闰月。
- 若实现与已有ADR冲突，应明确指出冲突与取舍，不能静默覆盖。
- 历法/时区/换日约定属于算法决策，变化时须执行独立算法复核。
