# 计划：README「CLI 非交互 / 脚本调用」补充 `--help` 示例

在 `README.md` 的「CLI 非交互 / 脚本调用」小节（`#### CLI 非交互 / 脚本调用`，第 229 行起）的 bash 代码块**末尾**追加一行示例：

```bash

**完成判据**：该代码块的最后两行严格为 `# 查看全部参数` 与 `uv run src/cli.py --help`；README 其余内容逐字不变。

**范围外**：README.md 以外的任何文件；任何代码改动。（`--help` 由现有 `argparse.ArgumentParser` 提供，已实测退出码 0，无需代码变更。）

`README.md` 第 231–249 行为该 bash 代码块，当前最后一行是：

```
uv run src/cli.py --numbers 1,2,3 --question "近期求职" --json

其下一行（第 250 行）即为代码块结束围栏 ```` ``` ````。代码块内各示例之间以**空行**分隔，每个示例由「注释行 + 命令行」两行组成。

## 具体改动

在 `README.md` 第 249 行之后、第 250 行结束围栏 ```` ``` ```` 之前，插入三行内容：

1. 一个空行（与块内既有示例之间的分隔空行保持一致）；
2. `# 查看全部参数`
3. `uv run src/cli.py --help`

插入后片段应为：

```bash
# AI 解读同时保留结构化输出；失败时 interpretation 为 null 并给出 error
uv run src/cli.py --numbers 1,2,3 --question "近期求职" --json

uv run src/cli.py --help
```

注意：

- 不要在注释与命令之间插空行——否则代码块最后两行不再是「注释 + 命令」，不满足完成判据。
- 不要改动代码块外的正文（`#### CLI 非交互 / 脚本调用` 下方的项目符号列表等）。
- 保持既有缩进/风格：无前导空格，命令为裸 `uv run ...`。

1. `sed -n '229,256p' README.md`，确认新示例位于代码块末尾，且其下**紧邻**结束围栏 ```` ``` ````（中间只有一个空行分隔符在注释前，注释与命令相邻）。
2. 精确断言最后两行：
