# 三传 Prompt 联读与针对性

状态：实现与离线验收完成。基线：`9b44682`，`master`，工作树干净。

## 问题与范围

用户明确：九宫算法仅在有清晰改进证据时修改，重点是给AI模型的三传解读Prompt。现有三次模运算、九宫规则及边界对照无明确缺陷，本轮保持所有计算、数据、输入映射和历法原样。

现有Prompt已规定五段结构与事实边界，但仍可能产生三个独立词条，按不同问题给出可互换的套话，或重复建议。本轮只修改系统Prompt文字并建立人工质量评测资料，不改变请求JSON、模型选择、预算、SDK和UI。

## 用户故事与验收

1. 用户能看懂三传连贯的变化：一句话判断概括三传主线，末传综合前两传；引用两段已有关系，不新增首末关系/术数规则，不把象征解释当成现实因果。
2. 用户的具体目标影响解释：先识别所问目标、已有事实与关键不确定项；如用户提供时间范围，只作为讨论范围，不能生成新的应期。
3. 同一组三传在不同目标下有不同的解释重点，而不是只替换问题名。未知情况写成条件；不能把假设描述成用户事实，也不能把每一传强行对应某个人物。
4. 每传保留依据、白话、建议；建议限一句。末尾汇总两项优先行动，说明先做什么、核实什么及何种条件下调整，避免复述各段。
5. 重复符号说明共同主题，不凑三份词条、不强造戏剧性转折，也不按重复次数放大吉凶概率。
6. 维持既有五个标题、450–700字目标、2400 tokens预算、问题隔离与条件性表达；加入短的联读与目标差异示例，明确示例不是本次结果。
7. 建立至少8个固定人工评测场景，覆盖同卦不同问题、求稳/求变、全重复、逆向关系、信息不足及用户请求虚构。每例含输入、独立核对的符号/关系、必需表现及失败信号。
8. 评分区分计算事实忠实度、联读、针对性、直观程度、行动质量；记录真实模型、版本、参数、Prompt版本，做配对盲评。不能用离线测试或“出现关键词”作为实际质量提升证明。
