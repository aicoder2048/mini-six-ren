# Mini Six Ren Project

小六壬占卜系统 - 一个基于Python的中国传统占卜和命理分析应用。

## 项目简介

Mini Six Ren（小六壬）是一个集成了多种中国传统文化元素的占卜应用，包含：

- **小六壬占卜** - 使用本项目九宫轮转规则计算三传（不同于六宫流派）
- **八字测算** - 根据出生时间计算生辰八字并进行命理分析
- **五行分析** - 完整的五行相生相克关系分析
- **历法转换** - 公历农历相互转换
- **笔画计算** - 汉字笔画数计算和分析

## 功能特色

### 🔮 小六壬占卜
- 支持三种输入方式：数字、日期、汉字笔画
- 自动计算三传（初传、中传、末传）
- 五行生克关系分析
- 集成AI智能解读

### 🧮 八字测算
- 精确的公历农历转换
- 完整的生辰八字计算
- 日主强弱分析
- 配偶宫位解读
- 五行缺失影响评估

### 🎨 界面特色

#### CLI版本
- 美观的终端彩色界面
- 渐变色标题和菜单
- 分层式菜单结构
- 丰富的表格展示

#### Web版本
- 数字、日期、汉字三种输入，支持离线计算
- 桌面三列、手机纵向三传卡片，完整显示释义
- 本次输入与起课数字快照，五行关系明确标注方向
- 传统方位与神灵信息按需展开
- 可访问输入标签、等待/完成/失败状态，失败后保留本地结果

## 安装和运行

### 环境要求
- Python 3.13+
- uv 包管理器
- 支持所有平台：Windows、macOS (Intel/ARM64)、Linux

### 安装依赖
```bash
# 使用uv安装依赖
uv sync
```

### 运行应用

#### CLI版本（命令行界面）
```bash
# 启动小六壬占卜系统CLI版
uv run src/cli.py
```

#### Web版本（现代化网页界面）
```bash
# 启动小六壬占卜系统Web版
uv run src/web.py
```
然后在浏览器中访问 `http://localhost:8080`

Web先展示本地三传；选择AI并填写问题时再等待完整解读，生成期间显示等待状态。

### 依赖变更说明

**历法实现**：使用 [lunar-python](https://github.com/6tail/lunar-python) 完成双向公历/农历转换和八字计算，不需要编译原生扩展。八字年柱、月柱按节气划分；日柱采用 sect 2（午夜换日，23点仍属当日日柱，时柱沿用该库晚子时规则）。输入时间按北京时间 UTC+8 解释，不进行出生地或真太阳时校正。公历支持 1900–2099 年，农历转换结果也必须落在此范围内。

## 使用方法

### 1. 小六壬占卜

#### CLI版本使用
启动应用后选择"小六壬占卜"，然后：
1. **选择解读方式** - 可选择仅本地计算或可用的OpenAI/DeepSeek模型；没有密钥时自动使用本地模式
2. **选择输入方式**：
   - **数字输入**: 输入三个1–999整数（如：1,2,3）
   - **日期输入**: 输入公历日期和时间
   - **汉字输入**: 输入三个汉字，系统自动计算笔画
3. **立即查看本地三传结果**；选用AI后可输入问题，留空跳过解读。

#### Web版本使用
1. **选择起课方式**：三个1–999整数、北京时间、或三个汉字。
2. **选择解读方式（可选）**：仅本地计算或可用AI模型；填写具体问题以获得针对性解读。
3. **查看三传**：核对起课数字，阅读初传、两段关系和后续趋势；文化背景可展开。
4. **查看AI解读**：一句话判断 → 初传（起点）→ 中传（过程）→ 末传（趋势）→ 行动建议。每传都有依据、白话与建议。

日期模式按农历月、日、地支时辰编号取数；闰月沿用同名月份，23点仍用当日农历日及子时编号1。输入按北京时间解释，不自动换算其他时区。汉字笔画依内置字典，可能与其他字形/字典标准不同。

### 2. 八字测算
选择"八字测算"，输入：
- 公历出生日期（YYYY-MM-DD）
- 出生时间（HH:MM）
- 性别（M/F）

### 3. 工具功能
- **笔画计算**: 计算汉字笔画数
- **历法转换**: 在工具菜单选择“公历转农历”或“农历转公历”，后者需指定是否闰月
- **五行信息**: 查看详细的五行知识
- **日主分析**: 分析特定日期的五行属性

## 配置说明

### AI功能配置（可选）
所有三种占卜输入方式均可离线计算三传和五行关系，无需密钥。AI请求失败时保留本地结果。

如需使用AI智能解读功能，请：
1. 创建`.env`文件
2. 添加至少一个AI模型的API密钥：
   ```
   # OpenAI GPT-4o (推荐)
   OPENAI_API_KEY=your_openai_api_key_here
   
   # DeepSeek Chat (可选)
   DEEPSEEK_API_KEY=your_deepseek_api_key_here
   ```

### 支持的AI模型

应用支持以下AI模型进行占卜解读：

#### OpenAI GPT-4o
- **模型标识**：`openai:gpt-4o`
- **API密钥**：`OPENAI_API_KEY`
- **特点**：高质量解读，响应准确

#### DeepSeek Flash
- **模型标识**：`deepseek:deepseek-flash`（指向 DeepSeek-V4.1-Flash）
- **API密钥**：`DEEPSEEK_API_KEY`
- **特点**：经济实惠，支持中文优化

**智能模型选择**：
- 应用会自动检测可用的模型
- CLI提供本地模式和模型选择菜单；Web默认选择第一个可用模型，也可切换为本地模式
- 未设置任何API密钥时自动使用本地模式
- 仅在选择AI模型且问题非空时发起请求

#### 五行关系说明

关系以左传为主语，CLI、Web和AI共享同一份计算结果：

| 关系 | 含义 | 示例 |
|---|---|---|
| 生 | 前传生后传 | 木→火：木生火 |
| 克 | 前传克后传 | 木→土：木克土 |
| 被生 | 后传生前传 | 木→水：水生木 |
| 被克 | 后传克前传 | 木→金：金克木 |
| 比和 | 同一五行 | 木→木：同属木 |

相生与相克顺序参考[《白虎通·五行》](https://ctext.org/bai-hu-tong/wu-xing2/zh)。九宫符号及文化归属沿用项目数据，不以此证明现实预测效力。

`Prediction`结构保持不变，但原关系值“无”现细分为“比和、被生、被克”；外部调用方若匹配关系字符串需同步更新。符号与起课结果未改变。

## Prompt 的设计与验证

AI收到结构化的本地符号、五行、关系及中性释义，问题作为独立用户数据。系统提示要求专业术语紧接白话解释，针对问题给出可行动建议，并说明趋势成立的条件。三传不用于推算确定期限、概率或他人真实想法。

离线测试通过模型请求边界检查两种调用路径发送相同事实和结构要求，未调用付费模型。Prompt约束不等于模型输出保证，真实模型的语言质量与指令遵循仍需人工评测。

进一步要求三传联读、按用户目标选择含义、区分事实与假设，并去除重复建议。详见[Prompt质量规格](docs/specs/prompt-quality.md)及[9个固定人工评测场景与评分标准](docs/evals/three-transmissions.md)。后者尚无真实在线A/B结果。

可复现本轮算法独立审计：

```bash
uv run python scripts/audit_interpretation_algorithm.py
```
