# 小六壬 Web 视觉改进

Status: ready-for-agent

## 问题

现有 Web 页面以深色纵向表单为主，输入、等待与结果缺少清晰的视觉层次，传统文化主题表达不足。

## 方案与用户故事

采用暖白纸本、松绿与朱砂的东方编辑式视觉。桌面端并排呈现起课表单和三传结果，移动端纵向阅读。

1. 用户进入页面即可辨识产品、起课入口及使用说明。
2. 用户可使用数字、时间、汉字三种现有方式起课，原校验、默认值和计算语义保持一致。
3. 起课前可看到明确的等待状态与三传阅读提示，不展示虚构结果。
4. 起课后可查看输入快照、初传/中传/末传、五行关系与传统文化背景。
5. 用户仍可选择可用 AI 或本地模式，并填写问题；AI 失败时本地结果保留。
6. 用户可通过导航打开使用说明与关于内容，键盘可以操作表单与对话框。
7. 在窄屏上表单、结果、错误和长问题正常换行，无横向滚动；减少动态效果偏好受到尊重。

## 实现决策

- 保持 NiceGUI、每请求独立控制器与原计算服务；视觉样式、装饰图形单独存放。
- 使用本地 CSS、SVG 和系统字体，无新增运行依赖及外部图片请求。
- 本次只调整展示、导航和布局，不新增算法、输入映射、历法规则或领域数据。

## 验证

复用既有 Web 控制器和回归测试；浏览器检查桌面/移动端、三种起课方式、非法输入恢复、弹窗与控制台错误。
执行完整 unittest、uv lock --locked、git diff --check，按规范与规格双轴独立审查。
