# Web 皮肤/主题

## 范围

在现有 NiceGUI 页面上增加可切换的皮肤（主题）。当前"暖白纸感 · 朱砂主色"界面保持为默认皮肤且视觉不变；新增三套视觉上有明显创意差异、并带有各自交互效果的皮肤。沿用全部输入校验、取数、历法与 AI 行为；不新增算法、服务或远程发布。

## 皮肤清单

| id | 名称 | 视觉 | 交互 |
|---|---|---|---|
| `paper` | 素纸（默认） | 现有暖白纸感与朱砂主色；`web.css` 既有视觉规则不变，仅追加切换控件样式、头部换行策略（`.site-header`/`.brand`/`.header-actions` 的换行与窄屏间距）及减少动态效果下的动画迭代次数限制 | 现有行为 |
| `night` | 星夜 | 深空渐变底、鎏金强调色、毛玻璃卡片、五行分色徽章、缓慢转动的星盘 | Canvas 星空闪烁与流星、随指针移动的提灯光晕、三传卡片交错浮现 |
| `ink` | 水墨 | 宣纸白与墨黑、桌面竖排标题、笔触分隔、朱文印章徽章、墨晕背景、圆相空状态 | 印章盖印入场、三传墨晕显现、悬停时符号名下划墨线 |
| `neon` | 霓虹 | 深黑底、青/品红荧光、网格地面、扫描线、HUD 角标、五行荧光分色 | 切换时 CRT 开机动画、标题悬停故障字效、卡片悬停扫描光带、状态行闪烁光标 |

## 设计与验收

- 页面头部提供皮肤切换控件：每个皮肤一个带色样与名称的按钮，`role=group`、`aria-label`、`aria-pressed` 可访问，键盘可操作；窄屏只显示色样。
- 切换完全在浏览器端完成（`html[data-theme]` 属性 + 各主题 CSS），不经服务器往返，不刷新页面；选择写入 `localStorage`，再次访问保持；`?theme=<id>` 可指定并记忆；无效值回落默认。
- head 内联脚本在首屏绘制前应用已保存的皮肤，避免闪烁。
- 主题 CSS 只匹配自身 `html[data-theme="<id>"]`，不影响默认皮肤；暗色皮肤覆盖 Quasar 输入框、下拉菜单、对话框、折叠面板与 `--q-primary`。
- 主题 JS 效果只在对应皮肤激活时启动，切走时完整清理（画布、监听器、CSS 变量）；遵守 `prefers-reduced-motion`；页面隐藏时暂停动画。
- 三传卡片与五行徽章带 `data-element` / `element-<key>` 钩子供主题分色，默认皮肤不使用这些钩子，因此外观不变。
- 所有皮肤下：三种输入方式、模型选择、指南对话框、空状态、结果、文化背景、AI 解读与错误/等待状态均可读可用；桌面与手机断点不产生水平溢出。
- 不引入外部字体、图片或脚本网络请求；每次页面请求仍创建独立 `DivinationWebApp`。

## 计划

1. `web.py` 增加主题注册表、切换控件、样式/脚本注入与元素钩子；`web.css` 追加切换控件样式、头部换行策略与减少动态效果的迭代次数限制，既有视觉规则不变。
2. 编写 `src/themes/theme.js` 与三套主题 CSS。
3. 单元测试覆盖注册表完整性、切换控件渲染、注入内容与五行钩子；浏览器逐皮肤验收桌面/手机。
4. Standards、Spec 独立审查，记录验收并本地提交。
