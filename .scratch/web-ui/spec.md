# Web 界面改进

## 范围

改善现有 NiceGUI 小六壬页面的视觉层次、表单体验与响应式阅读体验。沿用项目九宫法及所有现有输入校验、取数、历法与 AI 行为；不新增算法、服务或远程发布。

## 设计与验收

- 暖白纸感背景、墨色文字与朱砂主色，中文衬线标题；页面具有品牌导航、简介、起课表单、结果区和页脚。
- 桌面并列展示起课表单与结果；窄屏顺序排列，不产生水平溢出。
- 保留数字、时间、汉字三个有标签的输入方式，默认值和合法范围不变。
- 保留模型选择和问题输入；无可用模型时说明本地计算能力；使用说明可打开和关闭。
- 初始结果区有明确的空状态及三传阶段说明；成功后完整展示输入快照、三传释义、方向关系和可展开文化背景。
- 等待、错误、完成状态仍可访问；AI 失败保留本地结果；不同客户端状态独立。
- 支持键盘可见焦点与减少动态效果偏好，样式和装饰无需外部字体或图片网络请求。

## 计划

1. 重排页面与结果布局，提取独立样式文件。
2. 验证已有回归测试、锁文件与浏览器桌面/手机交互。
3. Standards、Spec 独立审查，记录验收并本地提交。
