# Web 首屏布局调整

## 范围

在皮肤功能（`b5d929c`）之上调整首屏布局，让首次用户在不滚动的情况下看到起课输入、主按钮与结果区。沿用全部输入校验、取数、历法与 AI 行为；不新增算法、服务或远程发布。

## 问题

- 页头 104px 与主视觉约 216px 占据首屏三分之一，表单中"心中所问 / 解读方式"两块选填内容排在主按钮之前，主按钮在常见 860px 视口内不可见。
- 按钮文案"查看三传"是结果术语而非动作，对首次用户不友好。
- 水墨皮肤桌面竖排标题需要约 350px 高度，右侧三分之二区域空白。
- 未配置 AI 时"解读方式"只有一个选项、问题不参与计算，却始终完整展开。

## 设计与验收

- 页头最小高度 104→88px（≤900px 为 80px）；主视觉改为两行：眉题一行，标题（28–36px）与副标题同一行、基线对齐，窄屏自动换行。
- 表单顺序：起课方式 → 输入 → 错误提示 → **开始占卜** 按钮 → 状态行 → 可折叠"心中所问 · 解读方式"选填区。配置了可用 AI 模型时选填区默认展开，否则默认收起并说明"本地无需 AI"。
- 主按钮文案改为"开始占卜"，就绪状态文案同步；处理中文案"正在计算…/正在解读…"与完成/失败文案不变。
- 卡片内边距与间距收紧，问题框最小高度 80→56px，去掉"选一个方式，从此刻开始。"冗余提示；空状态引导文案写明「开始占卜」。
- 水墨皮肤主视觉改横排：粗体标题配笔触下划线，朱印横排置右，水印「觀」缩小到主视觉带内；竖排规则移除。
- 星夜、霓虹、水墨为折叠区提供与各自面板一致的边框、背景与标题色。
- 1440×900 视口下四套皮肤的主按钮与右侧空状态位于首屏；390px 视口主按钮位于首屏，无横向溢出；点击后三传结果在桌面首屏可见。
- 现有输入默认值/范围、模型选项、结果内容与 AI 流程不变；`question_input`、`model_select` 仍可由测试直接赋值。

## 基线

`b5d929c`；开始时工作树干净。
